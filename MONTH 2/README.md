# Month 2 — Agentic RAG Journey

Each `dayN.md` file is a full explanation of that day's notebook — what problem it solved, a line-by-line walkthrough of the real code, a flowchart of how it works, and what actually happened when it ran (including real bugs found along the way).

Open any `dayN.md` file directly on GitHub to read it with the diagrams rendered — no download needed.

- **Week 1** (Days 1–7): Learning to build tools — schemas, agents, calculators, routing, hallucination defense.
- **Week 2** (Days 8–13): Building an agent's reasoning by hand — ReAct, Plan-and-Execute, self-correction, a real 20-question audit.
- **Week 3** (Days 14–20): Rebuilding everything as a LangGraph state machine — cycles, checkpoints, human approval, multi-agent teams.
- **Week 4** (Days 21–25): Four layers of memory — short-term, long-term, summary, and entity memory, tested end to end.

A single combined PDF and markdown version of the whole month is also available: `My Month 2 Journey.pdf`.
